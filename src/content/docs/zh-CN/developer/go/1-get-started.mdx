Go 扩展就是一份普通的 Go 源文件（`.go`），宿主使用 [Scriggo](https://github.com/open2b/scriggo) 引擎编译运行。它适合需要更强类型、复杂解析或使用 Go 生态库的场景。

本页介绍如何**创建扩展文件与声明入口函数**；`sdk` 的详细用法、返回类型与 Scriggo 限制请见 [详细用法](/docs/developer/go/2-detail-usage/)；本地以原生 Go 开发与运行时交给 Scriggo 执行两种驱动方式见 [原生 Go 运行](/docs/developer/go/3-running-native/) 与 [Scriggo 运行](/docs/developer/go/4-running-scriggo/)。通用元数据见 [开始开发](/docs/developer/2-extension/)，返回结构见 [数据格式](/docs/developer/5-data/)。

## 创建扩展文件

新建一个与包名同名的 `.go` 文件，例如 `my.extension.go`。文件是一个普通的 Go package，通过 `go get` 引入官方 SDK：

```bash
go get github.com/miru-project/miru-core/pkg/extension/golang/sdk
```

## 入口函数

Go 扩展通过**导出函数**暴露入口，宿主按函数名调用：

```go
import sdk "github.com/miru-project/miru-core/pkg/extension/golang/sdk"

// 参数顺序：pkg string 在前，其余为业务参数
func Latest(pkg string, page int) ([]sdk.ExtensionListItem, error) { /* ... */ }
func Search(pkg string, kw string, page int, filter string) ([]sdk.ExtensionListItem, error) { /* ... */ }
func Detail(pkg, url string) (*sdk.ExtensionDetail, error) { /* ... */ }
func Watch(pkg, url string) (*sdk.ExtensionWatch, error) { /* 返回镜像列表（或 @type all 的 ExtensionAllMirror） */ }
func Mirror(pkg, url string) (*sdk.ExtensionBangumiWatchMirror, error) { /* 解析最终播放结构 */ }
func Load() { /* 扩展加载时执行一次（可省略） */ }
```

:::tip
宿主调用 `Watch` 时只接受两种返回形状：通用 V2 的 `ExtensionWatch`（分组镜像列表，再由 `Mirror` 解析），或组合型 `ExtensionAllMirror`（仅 `@type all` 使用，内部包含 manga/fikushon/bangumi 成员）。**独立的单类型 watch 形状（manga/fikushon/bangumi）不能作为 `Watch` 的返回值**——它们只作为 `ExtensionAllMirror` 的成员出现，或由 `Mirror` 返回。
:::

## 提交扩展

请通过 PR 将扩展提交到 `Miru 扩展仓库`，PR 中需包含扩展源文件，**不需要** `index.json`。
