Miru Alpha 的插件系統同時支持 **JavaScript** 與 **Go** 兩種語言運行時：

- **JavaScript 運行時**：基於 [goja](https://github.com/dop251/goja)（純 Go 實現的 ECMAScript 引擎），插件文件後綴為 `.js`。
- **Go 運行時**：基於 [Scriggo](https://github.com/open2b/scriggo)（Go 語言的模板/腳本引擎），插件文件後綴為 `.go`。

兩種插件使用同一套元數據與數據返回結構，前端對兩者一視同仁。開發插件需要一定的 JavaScript 或 Go 基礎，以及正則表達式知識。如果還不熟悉正則表達式，可以先學習 《[正則表達式和字符串的方法](https://zh.javascript.info/regexp-methods)》 與 《[正則表達式 30 分鐘入門教程](https://deerchao.net/tutorials/regex/regex.htm)》。

本文檔默認你已按 [開發環境](/developer/1-environment/) 配置好環境。

## 插件元數據

無論是 JS 還是 Go 插件，文件頂部都必須用註釋包裹一份元數據，格式為 `// ==MiruExtension==` … `// ==/MiruExtension==`。

```text
// ==MiruExtension==
// @name         My Extension
// @version      v0.0.1
// @author       YourName
// @license      MIT
// @lang         zh-cn
// @icon         https://example.com/icon.png
// @package      my.extension
// @type         bangumi
// @webSite      https://example.com/
// @apiVersion   2
// ==/MiruExtension==
```

:::tip
必填字段：`@name`、`@version`、`@package`、`@webSite`、`@type`、`@apiVersion`。
- `@package` **必須**與插件文件名一致（不含 `.js` / `.go` 後綴）。
- `@type` 決定插件的內容類型，可選值：`bangumi`（動畫）、`manga`（漫畫）、`fikushon`（小說）、`all`（三者合一）。
- `@apiVersion`：JS 插件填 `2` 使用新版 API（推薦）；Go 插件默認即為 V2，可省略。
- `@license`、`@lang`、`@icon`、`@description`、`@tags` 等為可選項。
:::

## 選擇運行時

元數據寫好後，按你的語言選擇對應的開發指南，其中包含完整的入口函數、請求/緩存 API 與可運行示例：

- **JavaScript**：[JavaScript 插件 V2（goja）](/developer/js/1-get-started/)（推薦）；沿用舊寫法的請看 [JavaScript 插件 V1（舊版）](/developer/js/2-legacy-v1/)。
- **Go**：[Go 插件（Scriggo）](/developer/go/1-get-started/)

返回值結構（列表項、詳情、按類型區分的播放結構等）統一在 [數據格式](/developer/5-data/) 中定義。
