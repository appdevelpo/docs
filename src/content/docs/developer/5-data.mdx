本頁定義每個擴展入口的**輸入參數和返回結構**，與 [JavaScript 擴展 (V2)](/developer/js/1-get-started/) / [Go 擴展](/developer/go/1-get-started/) 中的入口函數一一對應。

- **V2（當前標準）**：`watch()` 返回鏡像列表，`mirror(url)` 再解析為下方的按類型播放結構。新擴展必須使用 V2。
- **V1（舊版兼容）**：`watch()` 直接返回最終播放結構，沒有 `mirror()` 步驟——詳見頁尾[數據格式（V1 舊版）](#數據格式v1-舊版)。僅存量插件參考。

:::tip
V1 與 V2 的核心區別在 `watch`：V1 的 `watch()` **直接返回最終播放結構**；V2 的 `watch()` 返回**鏡像列表**（`WatchList`），用戶選好鏡像後，前端再調用 `mirror(url)` 解析成下面的按類型播放結構（`BangumiWatch` / `MangaWatch` / `FikushonWatch`）。兩種版本的**按類型播放結構本身完全一致**——差別只在 `watch` 的契約。
:::

```json title="帶字幕和 TLS 指紋偽裝的 HLS 鏡像"
  "url": "https://cdn.example.com/video.m3u8",
  "headers": { "Referer": "https://example.com/" },
  "subtitles": [
    { "language": "en", "title": "English", "url": "https://cdn.example.com/subs/en.vtt" }

```

```json title="Torrent 鏡像"

```

:::note
設置 `tlsConfig` 後，後端會自動將鏡像中的所有 URL 改寫為 localhost 代理 URL。插件作者始終返回**原始上游 URL**。
:::

## 數據格式（V1 舊版）

舊版 V1 插件以 `class extends Extension` 方式編寫，`watch()` 直接返回最終播放結構，沒有 `mirror()` 步驟。其返回結構與上面 V2 的 `BangumiWatch` / `MangaWatch` / `FikushonWatch` 一致，區別僅在 `watch` 的契約：

```javascript
// V1 入口（兼容參考）
class Extension {
  latest(page) { /* ... */ }
  search(kw, page, filter) { /* ... */ }   // V1 同樣接收 filter 參數，可忽略
  detail(url) { /* ... */ }
  watch(url) {
    // 直接返回最終播放結構
    return { type: "hls", url: "https://.../a.m3u8", headers: {} };
  }
  load() { /* ... */ }
}
```

:::caution
V1 已不再推薦用於新插件；新插件請統一使用 V2（見 [JavaScript 插件](/developer/js/1-get-started/) 與 [Go 插件](/developer/go/1-get-started/)）。
:::
