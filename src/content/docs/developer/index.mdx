歡迎參與 Miru Alpha 的插件開發，本文檔將幫助你快速瞭解 Miru Alpha 的插件開發方法和注意事項，讓你能夠輕鬆地為 Miru Alpha 添加新插件源。

Miru Alpha 的插件同時支持兩種語言運行時：**JavaScript（goja）** 與 **Go（Scriggo）**。你可以根據需求選擇——JS 適合快速編寫、門檻低；Go 適合複雜解析與複用 Go 生態庫。兩種插件使用同一套元數據與數據返回結構，前端對兩者一視同仁。

本文檔的目標受眾是想要參與 Miru 插件開發的貢獻者，你需要具備一定 JavaScript 或 Go 的基礎知識，以及對 Miru 的基本瞭解。本文檔按照開發流程來劃分，每個部分包含以下內容：

- 開發環境：介紹如何搭建 Miru 的插件開發環境，包括克隆源碼、運行服務，以及 JS / Go 各自的推薦工具鏈。
- 開發方法：介紹如何使用 Miru 的接口來實現插件開發（JavaScript 與 Go 兩套寫法），包括添加新插件源。
- 開發示例：給出一些插件開發的代碼示例和註釋，幫助你更直觀地理解。
- 開發注意事項：提供一些插件開發的注意事項和建議，幫助你避免一些常見的錯誤和問題。

本文檔使用正式的語言和圖文並茂的方式，以便於你快速、準確、清晰地掌握 Miru 的插件開發方法。本文檔使用線性的順序，你需要按照順序閱讀每個部分。

## 閱讀順序

1. **環境搭建**：搭建本地開發環境、運行服務。
2. **開始開發**：填寫插件元數據，並選擇你使用的語言（JavaScript 或 Go）。
3. **語言開發指南**：進入對應語言的頁面——
   - **JavaScript 插件**：[快速開始（V2）](/docs/developer/js/1-get-started/)（推薦）/ [舊版 V1](/docs/developer/js/2-legacy-v1/)（兼容）/ [數據格式（V2 / V1 舊版）](/docs/developer/5-data/)。
   - **Go 插件**：[快速開始](/docs/developer/go/1-get-started/) → [詳細用法](/docs/developer/go/2-detail-usage/) → [原生 Go 運行](/docs/developer/go/3-running-native/) / [Scriggo 運行](/docs/developer/go/4-running-scriggo/) → [數據格式](/docs/developer/5-data/)。
   
   這些頁麵包含該語言的入口函數、請求/緩存 API、內置模塊（`require` / `sdk`）與可運行示例，是你編寫插件時主要參考的頁面。
4. **數據格式**（[數據格式（V2 / V1 舊版）](/docs/developer/5-data/)）：所有入口方法的入參與返回結構參考；V2 為當前標準，V1 舊版僅作兼容保留，二者按類型播放結構一致。

:::tip
不確定選哪種語言？想快速上手、門檻低就選 **JavaScript（goja）**；需要複雜解析或複用 Go 生態庫就選 **Go（Scriggo）**。兩種插件的元數據與返回結構完全一致。
:::
